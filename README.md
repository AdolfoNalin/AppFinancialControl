# App Financial Control

Aplicativo de controle financeiro desenvolvido em .NET MAUI para gerenciamento de receitas, despesas e acompanhamento financeiro. Todo isso sem precisar de internet.

## 📋 Sobre o projeto

O objetivo do projeto é permitir que o usuário controle suas finanças pessoais de forma simples e intuitiva.

Principais funcionalidades:

- Cadastro de usuários
- Login com autenticação
- Cadastro de receitas
- Cadastro de despesas
- Consulta de extrato
- Controle de saldo
- Gráficos financeiros
- Filtros por período

## ⚙️ Como executar

```bash

```

### 2 Abra no Visual Studio 2022 ou 2026

- MAUI Workload
- Android SDK

Depois execute o projeto MAUI.
